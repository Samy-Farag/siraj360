# أصوات المعلّمين — سِراج 360° ومناسك 360°

ضع في هذا المجلد ملفات التصدير (‎.json) التي تنزّلها من:
- «🎙️ مراجعة الأصوات» ← «⬇ تصدير التسجيلات» في سِراج 360°
- «المكتبة الصوتية» ← «⬇ تصدير التسجيلات» في مناسك 360° (أصوات المرشد)

بعد الرفع يُعاد نشر الموقع تلقائياً خلال دقائق، فيسمع جميع الطلاب أصوات المعلّمين بدل القراءة الآلية.
يمكن رفع أكثر من ملف (ملف لكل معلّم أو لكل درس). إذا تكرر صوت البوابة نفسها في ملفين، يُعتمد الملف الأحدث اسماً.
